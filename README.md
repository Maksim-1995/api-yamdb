# YaMDb — API для отзывов на произведения


**YaMDb** — это учебный командный проект, реализующий REST API для сервиса по сбору отзывов пользователей на произведения (книги, фильмы, музыка).  
Произведения разделены по категориям и жанрам, пользователи могут оставлять текстовые отзывы, ставить оценки и комментировать чужие рецензии.  
Права доступа разграничены по ролям: аноним, аутентифицированный пользователь, модератор и администратор.


## Используемые технологии

- **Python 3.11**
- **Django 5.1** — веб‑фреймворк
- **Django REST Framework 3.15** — построение API
- **PyJWT** — создание и верификация JWT‑токенов
- **django‑filter** — фильтрация запросов
- **SQLite** — база данных по умолчанию
- **Pytest** — тестирование

## Пользовательские роли и права доступа

    Аноним — может просматривать описания произведений, читать отзывы и комментарии.
    Аутентифицированный пользователь (user) — может читать всё, как и Аноним, может публиковать отзывы и ставить оценки произведениям (фильмам/книгам/песенкам), может комментировать отзывы; может редактировать и удалять свои отзывы и комментарии, редактировать свои оценки произведений. Эта роль присваивается по умолчанию каждому новому пользователю.
    Модератор (moderator) — те же права, что и у Аутентифицированного пользователя, плюс право удалять и редактировать любые отзывы и комментарии.
    Администратор (admin) — полные права на управление всем контентом проекта. Может создавать и удалять произведения, категории и жанры. Может назначать роли пользователям.
    Суперпользователь Django должен всегда обладать правами администратора, пользователя с правами admin. Даже если изменить пользовательскую роль суперпользователя — это не лишит его прав администратора. Суперпользователь — всегда администратор, но администратор — не обязательно суперпользователь.

## Получить список всех произведений
GET /api/v1/titles/

## Добавить новое произведение (только администратор)
POST /api/v1/titles/
Authorization: Bearer <токен>
Content-Type: application/json

{
  "name": "1984",
  "year": 1949,
  "description": "Роман‑антиутопия",
  "genre": ["roman"],
  "category": "books"
}
